A crucial compatibility fix mod for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)**. It re-enables eyebrow slot rendering on legacy hairstyle and eyebrow mods that became incompatible with newer updates.

---

## 🎮 Features

- Re-enables the brow slot on older hair/eyebrow mods.
- Prevents eyebrows from disappearing when equipping custom hairstyles.
- Compatible with MDRG version **v0.97.12** (Target: `0.97.11`).

---

## ⚙️ Mod Type

This is an **Internal Mod**, designed to be imported, enabled, and managed directly using MDRG's built-in in-game mod manager (available on PC, Mac, and Android). It does not require external modding tools or loaders such as LemonLoader.

Ready-to-use mod packages are available under the [**Releases**](https://github.com/MDRG-MODS/brow-fix/releases) tab.
