A crucial compatibility fix mod for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)**. It re-enables eyebrow slot rendering on legacy hairstyle and eyebrow mods that became incompatible with newer updates.

---

## 🎮 Features

- Re-enables the brow slot on older hair/eyebrow mods.
- Prevents eyebrows from disappearing when equipping custom hairstyles.
- Verified 100% working on MDRG version **v0.97.12** (Target: `0.97.11`).

---

## 📥 Installation

1. Go to the [**Releases**](https://github.com/MDRG-MODS/brow-fix/releases) page and download `browfix.zip`.
2. Navigate to your MDRG installation directory:
   ```text
   .../My Dystopian Robot Girlfriend/FactorialOmega_Data/StreamingAssets/Mods/
   ```
3. Extract `browfix.zip` directly into your `Mods/` directory so that `mod.json` is located at:
   ```text
   .../StreamingAssets/Mods/browfix/mod.json
   ```
4. Launch the game and enable it in the mod manager.
